# AI Research Assistant —— 30～60 秒产品极速演示脚本（Demo Script）

> **文档路径**：`demo/README.md`  
> **配套演示 PDF**：`demo/sample_attention_is_all_you_need.pdf`（基于 [arXiv:1706.03762](https://arxiv.org/abs/1706.03762) 原文生成）  
> **配套完整分析报告**：`demo/01_paper_analysis.md`

---

## 一、演示前准备（10 秒）

1. 在项目根目录启动服务：
   - **Windows PowerShell**：`.\scripts\start.ps1`
   - **WSL2 Ubuntu**：`bash scripts/start.sh`
2. 打开浏览器访问前端地址：`http://localhost:3000`。

---

## 二、30～60 秒六步标准演示脚本（精确到秒）

| 时间轴 | 演示动作（Action） | 画面展示重点（Visual Focus） | 配套演示解说词（Narration） |
| :--- | :--- | :--- | :--- |
| **00:00 - 00:08**<br>**Step 1：打开产品主页** | 打开 `http://localhost:3000`，浏览首屏 Hero 区与三大功能矩阵，点击 **「进入论文工作台」**。 | 展示简洁专业的学术 SaaS 界面、顶部后端在线状态灯以及 P0/P1/P2 功能入口。 | “这是我们开发的 AI Research Assistant。它专为研究生和科研人员打造，核心目标是把冗长的英文论文 PDF 转化为句句可追溯原文页码的结构化知识。” |
| **00:08 - 00:18**<br>**Step 2：上传论文 PDF** | 在论文工作台选择 `demo/sample_attention_is_all_you_need.pdf` 上传（或点击「一键加载示例论文」）。 | 展示文件名、文件大小、安全校验通过提示以及 PyMuPDF 逐页提取出的页数（6 页，无扫描版异常）。 | “我们上传经典的《Attention Is All You Need》论文 PDF。系统自动完成文件头安全校验，并用 PyMuPDF 按页提取文本与元数据。” |
| **00:18 - 00:28**<br>**Step 3：触发论文分析** | 点击 **「开始结构化分析」** 按钮，观察状态从 `已上传` 变为 `已分析`。 | 展示分析进度状态切换，并显示当前所使用的分析引擎标识。 | “点击触发分析后，后端调用八模块防幻觉提示词与代码级数字核验器，自动完成 18 个学术维度的深度拆解。” |
| **00:28 - 00:42**<br>**Step 4：查看结构化报告** | 自动进入 **「报告详情页」**，依次展示基本信息、研究问题、核心方法、模型架构与实验结果。 | 重点停留展示 **Research Question**、**Methodology**、**Results（28.4 / 41.8 BLEU）**、**Contributions** 与 **Limitations**。 | “报告详情页按照顶会审稿逻辑呈现全部 18 个维度，研究问题、Scaled Dot-Product Attention 方法细节、数据集和局限性一目了然，原文未提及的内容一律诚实标注无法确认。” |
| **00:42 - 00:52**<br>**Step 5：展示原文引用与数字核验** | 向下滚动至报告底部的 **「原文溯源证据卡」** 与 **「实验数字一致性核验表」**，并切换到 **「论文问答」** 提问。 | 展示每条结论绑定的 `[Page 1]`、`[Page 3]` 页码徽章、英文原句摘录，以及 `28.4`、`41.8`、`512` 等数字的原文核实状态。 | “为了彻底解决 AI 幻觉，每条核心结论都绑定了精确页码和原文原句，所有实验数字都经过代码在原文中逐页核对；在问答页提问也能直接定位到原文对应页码段落。” |
| **00:52 - 01:00**<br>**Step 6：导出 Markdown** | 点击报告右上角 **「导出 Markdown 笔记」** 按钮，下载 `.md` 文件并展示。 | 浏览器立即下载生成的标准格式 `.md` 报告文件，可直接拖入 Obsidian 或 Notion。 | “最后点击一键导出 Markdown，即可获得包含 18 维分析与原文引用的标准文献笔记，无缝融入科研工作流。” |
