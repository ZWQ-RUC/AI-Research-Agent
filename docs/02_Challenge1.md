## 一、使用的核心提示词概述

本阶段采用 `docs/02_Project_Prompt.md` 中编写的**八模块结构化前端开发提示词**，围绕“现代学术 SaaS 风格、桌面端优先、拒绝花哨渐变、突出 18 维结构化报告与原文页码溯源”的目标完成了产品主页与一体化学术工作台的研发。

---

## 二、实际开发与工程修改过程

在云端开发环境落地前端工程时，我们执行了以下真实开发与工程适配步骤：

1. **第一阶段（基础页面骨架搭建）**：
   - 创建了 `frontend/package.json`、`tsconfig.json`、`next.config.ts`、`tailwind.config.ts` 及 `src/types/research.ts`、`src/lib/api.ts`，实现了集中式 API 客户端管理与统一错误捕获。
2. **第二阶段（首页八大要素与四大工作台视图整合）**：
   - 在首页实现了品牌导航栏、Hero 价值主张区、核心痛点对比、P0/P1/P2 三大功能模块卡片、四步标准工作流、产品优势矩阵与快速开始入口。
   - 实现了与后端 API 实时联动的四大功能视图：**论文工作台（P0）**、**论文报告详情页（18 维学术布局 + 原文证据卡 + 数字核验表）**、**论文智能问答页（P1 页码溯源检索）**、**实验对比分析页（P2 指标对比与零编造分析）**。
3. **第三阶段（离线/受限网络下的双模启动增强）**：
   - 考虑到云端沙盒及部分本地内网环境可能存在 npm 镜像拉取受限的情况，除了完整的 Next.js 工程源码外，我们额外编写了零外部依赖的高保真前端服务脚本 `frontend/server.mjs`，使得无论是否执行过 `npm install`，运行 `node frontend/server.mjs` 或 `scripts/start.ps1` / `scripts/start.sh` 均可在 `http://localhost:3000` 正常启动完整可交互的前端界面并与 `http://localhost:8000` 后端完成全流程联调。
