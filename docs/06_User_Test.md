# 第四份作业：真实用户试用反馈记录模板（User Testing Template）

> **文档路径**：`docs/06_User_Test.md`  
> **诚实性声明**：当前项目在云端开发环境中由自动化测试与开发团队完成了功能验证，尚未邀请外部真人用户操作。严格遵循《作业.md》“没有真实试用者时标记待填写，不允许编造用户反馈”的原则，以下为三位不同画像的目标用户预留了标准化试用任务与反馈记录表，供您在本地解压运行后邀请同学或同事填写。

---

## 一、试用测试总体方案

- **测试环境**：Windows 11 / WSL2 Ubuntu 24.04 本地运行环境（前端 `http://localhost:3000`，后端 `http://localhost:8000`）
- **标准试用任务包**：
  - **Task 1（P0 论文解析）**：上传一篇本专业的英文学术论文 PDF（或使用内置《Attention Is All You Need》PDF），生成 18 维结构化分析报告，核对原文证据卡的页码是否准确，并导出 Markdown 文件。
  - **Task 2（P1 论文问答）**：在论文问答页面针对论文的模型架构或实验设置提 2 个问题（含 1 个原文有答案的问题、1 个原文未提及的问题），观察引用页码与拒答表现。
  - **Task 3（P2 实验分析）**：在实验分析页面录入一组自己的 Baseline 与实验组对比指标，查看生成的对比分析报告。
