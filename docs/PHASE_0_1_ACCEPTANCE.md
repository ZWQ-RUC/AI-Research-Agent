# Phase 0 & Phase 1（P0 论文解析 + P1 论文问答）专项质量验收记录

> **文档路径**：`docs/PHASE_0_1_ACCEPTANCE.md`

---

## 一、P0 论文智能解析专项核验

1. **文件上传与边界安全**：
   - `.pdf` 扩展名 + `%PDF-` 魔数双重校验已实测通过；
   - 空文件（0B）返回 HTTP 400、超 30MB 文件返回 HTTP 413、损坏 PDF 返回 HTTP 422 已实测通过；
   - 空白页与扫描版 PDF 检测（返回 `scanned_warning` 状态与明确提示，不伪装 OCR）已实测通过。
2. **18 维结构化输出与缺失标注**：
   - 18 个字段全部由 Pydantic Schema 强类型约束，缺失项统一标注 `未在原文中找到 / 无法确认`。
3. **两大质量检查（原文可追溯 + 数字一致性）**：
   - 每份报告输出带页码与原句的 `evidences` 列表；
   - `verify_numbers_against_text()` 自动核验报告数字在原文中的出现页码并生成 `number_checks` 表格。

---

## 二、P1 论文智能问答专项核验

1. **按页分块检索**：将 PDF 每页文本切分为带 `page` 锚点的段落块，通过本地 BM25 + 双语学术同义词扩展实现毫秒级召回。
2. **原文引用与无依据拒答**：
   - 有原文依据的问题：返回准确解答并附带 `citations`（含页码、相关性得分、原文段落片段）；
   - 原文未提及的问题：明确返回 `无法从所上传论文原文中确认该问题的信息`，严防幻觉。
